# HadirPondok ? Download APK

Repository ini khusus distribusi paket instalasi HadirPondok. Source code aplikasi dan credential tidak dipublikasikan.

## Unduh versi terbaru

Buka [halaman Releases](https://github.com/assamarqondi0208-png/HadirPondok-Releases/releases/latest), lalu unduh file `.apk` pada bagian **Assets**.

Setiap rilis menyertakan checksum SHA-256 dan manifest verifikasi. Baca catatan kompatibilitas signing sebelum memperbarui instalasi lama.

Distribusi APK langsung ini bukan Google Play. Jangan menghapus aplikasi lama sebelum seluruh draft presensi tersinkron.
